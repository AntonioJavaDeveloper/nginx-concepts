📌 Endpoints principais(Java) + Laravel

Método Caminho Descrição
GET /api/games Lista todos os jogos
GET /api/games/{id} Retorna detalhes de um jogo
GET /api/lists Lista todas as listas de jogos
GET /api/lists/{listId}/games Lista os jogos de uma lista
- http://localhost/laravel Retorna a página inicial do Laravel
Os endpoints acima provém do servidor http://games1:9001 implementados em Java. Caso seja implementado load balancer pode ser verificado o nome do servidor que entrega a requisição pela chave "server" que se encontra no corpo do JSON. A requisição ao sistema em Laravel chega primeiramente ao servidor http://nginx-laravel:8083. Esse servidor encaminha a requisição ao servidor http://laravel1:9000. Todos esses servidores estão inacessíveis fora do contexto docker.

📌 Erros principais

Caminho Descrição
/abc Erro 404 - Endereço desconhecido. Erro capturado e entregue ao cliente diretamente pelo servidor proxy, http://nginx , encaminhando a paǵina HTML de erro 404.
/api/abc Erro 404 - Endereço desconhecido. Erro capturado por http://games1:9001 e repassado ao servidor proxy, http://nginx . O servidor proxy devolve ao cliente a página HTML correspondente ao erro 404.
/laravel/abc Erro 404 - Endereço desconhecido. Erro capturado por http://laravel1:9000 e tratado. O servidor PHP do Laravel repassa o header HTTP com status code 404 juntamente com um body HTTP com HTML personalizado de página de erro ao servidor web http://nginx-laravel:8083. O servidor web encaminha o cabeçalho de erro 404 e o body HTML ao servidor proxy, http://nginx. O servidor proxy descarta o body HTML personalizado de página de erro e analisa o header com status code 404. O servidor proxy devolve o HTML da página de erro padrão ao cliente.
/error Error 502 - Bad Gateway. O servidor proxy recebe a requisição do cliente e encaminha para o servidor http://server1:1000. Só que esse servidor só escuta na porta 8081. A comunicação não se estabelece. O servidor proxy devolve ao cliente a página HTML correspondente ao erro 502.
Todas páginas de erro são redirecionadas pelo servidor proxy. Se por ventura algum servidor entregar ao servidor proxy uma página de erro personalizada no body HTTP então o servidor proxy irá descartar o body HTTP e devolver ao cliente a página de erro padrão.

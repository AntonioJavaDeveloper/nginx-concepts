📌 Endpoints principais

Método Caminho Descrição
GET /games Lista todos os jogos
GET /games/{id} Retorna detalhes de um jogo
GET /lists Lista todas as listas de jogos
GET /lists/{listId}/games Lista os jogos de uma lista
Os endpoints acima provém do servidor localhost:9001 implementados em Java. O nome do servidor se encontra no corpo do JSON na chave "server".

📌 Erros principais

Caminho Descrição
/abc Erro 404 - Endpoint desconhecido
/error Error 502 - Proxy aponta para um dos servidores mas o servidor não escuta nessa porta
Todas páginas de erro são redirecionadas pelo servidor proxy
